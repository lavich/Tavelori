## Context

Пример слова сейчас — `{ greek, russian, target, source? }`. Он собирается в `describe()` в `content/build.ts`, едет в пакете внутри `PackageWord.examples`, хранится в базе внутри записи слова и показывается компонентом `ExampleBox` (`src/features/words/WordCardView.tsx`). `ExampleBox` вызывается в трёх местах: подробная карточка (`WordScreen.tsx`), знакомство и раскрытие после ответа (`exercises.tsx`). Выделение слова-цели делается по `indexOf(target)`.

Ревизия поставленного слова — хеш полей `SHIPPED_FIELDS` (`src/content/schema.ts`). `examples` в них входят, поэтому изменение разметки меняет ревизию. Отредактированные пользователем слова при переустановке сохраняют локальную версию (`edited`).

Для чтения фрагментов слова уже есть образец: `reading` в исходнике превращается в `Segment { text, ipa, explanation, start }`, где сборка сама вычисляет смещение `start` и падает, если сочетание не найдено.

Мотивация и объём — в proposal.md, требования — в `specs/greek-word-content` и `specs/lesson-authoring`.

## Goals / Non-Goals

**Goals:**
- Разметка, которую автор пишет коротко, а приложение читает без разбора текста на устройстве.
- Ни одного нового чтения словаря целиком: связанная карточка ищется по ключу при нажатии.
- Формат базы, полной копии и синхронизации не меняется.

**Non-Goals:**
- Разметка фраз (`content/phrases/`) и примеров пользовательских слов.
- Редактирование разметки в редакторе слова.
- Массовая переразметка существующих примеров. Кроме пилота, она пойдёт отдельными поручениями по урокам.
- Добавление слова в обучение из строки перевода, установка урока из неё.

## Decisions

### 1. Отрезки со смещениями, а не токенизация всего предложения

В исходнике автор перечисляет размечаемые отрезки по порядку:

```yaml
examples:
  - greek: "Το σπίτι μας είναι μεγάλο."
    russian: "Наш дом большой."
    target: "σπίτι"
    words:
      - { text: "Το", russian: "(артикль)" }
      - { text: "σπίτι", russian: "дом", word: w12-16 }
      - { text: "μας", russian: "наш" }
      - { text: "είναι", russian: "есть, является" }
      - { text: "μεγάλο", russian: "большой", word: w13-20 }
```

Сборка ищет каждый отрезок в предложении, начиная с конца предыдущего, и записывает в пакет `glosses: { start, length, russian, wordId? }[]`. В пакете тексты отрезков не дублируются: они восстанавливаются срезом предложения.

Альтернатива — полный список токенов, покрывающий всё предложение, включая пробелы и знаки препинания. Он избыточен: автору пришлось бы записывать `" "` и `"."`, а неразмеченные слова и так должны остаться простым текстом. Поиск по порядку решает и повтор слова в предложении: второе «το» находится после первого.

Смещения вычисляются по NFC-строке, так же как `Segment.start`. Разметка, в которой отрезок не найден, отрезки пересекаются или идут не по порядку, отклоняется сборкой.

### 2. Перевод хранится в отрезке, карточка — только ссылка

Перевод отрезка — перевод в этом контексте («μεγάλο — большой», а не «большой, крупный» из карточки). Он показывается без обращения к карточке. Это закрывает три случая сразу: у слова нет карточки (`μας`), карточка из неустановленного урока, карточка удалена. Ссылка `wordId` нужна только для действия «Открыть карточку».

Альтернатива — брать перевод из связанной карточки. Она требует, чтобы карточка была на устройстве, и не работает для служебных слов. Отвергнута.

Проверка ссылки в сборке идёт по всему каталогу, а не по уроку: пример урока 4.2 может ссылаться на слово урока 1.1.

### 3. Строка под предложением, а не всплывающая подсказка

Строка перевода показывается под текстом примера внутри `ExampleBox`, между греческим предложением и его переводом. Причины:
- в проекте нет компонента всплывающей подсказки, и для одной строки его заводить не нужно;
- на телефоне всплывающий слой перекрывает соседние слова и перевод предложения;
- строке достаточно `aria-live="polite"`, чтобы диктор её озвучил.

Отрезки — `<button>` без собственной рамки, с подчёркиванием пунктиром. Слово-цель остаётся выделенным, как сейчас. Если слово-цель тоже размечено, выделение и кнопка совпадают.

### 4. «Открыть карточку» — только в подробной карточке

`ExampleBox` получает режим: `linked` в `WordScreen`, `gloss-only` в `exercises.tsx`. В тренировке переход увёл бы из сессии посреди раскрытия. Строка там показывает только перевод.

В режиме `linked` при нажатии на отрезок со ссылкой читается одна запись слова по ключу. Если она есть и не удалена, показывается ссылка на `/words/:id`. Для ссылки на ту же карточку, в которой показан пример, действие скрыто. Чтение делается при нажатии, а не при открытии экрана: так экран не читает все связанные карточки заранее (`selective-data-access`).

### 5. Правка примера снимает разметку только при изменении греческого текста

Редактор (`WordEditorScreen.tsx`) снимает `glosses` у примера в момент, когда меняется его греческий текст (`editExample` в `src/domain/examples.ts`). Перевести смещения на новый текст надёжно нельзя, а неверная разметка хуже отсутствующей. Если пользователь вернёт прежний текст вручную, разметка не вернётся: это принято ради простоты. Правка русского перевода или слова-цели разметку не трогает, у нового примера её и не было.

### 6. Схема пакета остаётся версии 3

Поле необязательное и вложено в уже существующий объект примера. Читатель пакета копирует `examples` как есть, поэтому версия схемы не повышается. Читатель проверяет форму `glosses` так же, как остальные поля слова: отрезок вне предложения отклоняет пакет с ошибкой `schema`. Проверка нужна, потому что пакет — внешний ввод.

## Risks / Trade-offs

- [Ревизия меняется у всех слов, которым добавили разметку] → Это ожидаемо: неотредактированные слова обновятся при переустановке, отредактированные сохранят локальную версию. Пилот ограничен одним уроком, остальные уроки размечаются отдельными поручениями.
- [Автор ошибся в переводе отдельного слова] → Проверка сборки ловит только форму. Языковую корректность она не доказывает, как и для остального контента. Происхождение переводов записывается, отчёт агента это оговаривает.
- [Отрезок совпал не с тем вхождением] → Поиск идёт по порядку от конца предыдущего отрезка. Если автор пропустил первое вхождение, будет размечено оно, а не второе. Шаблон и инструкция требуют перечислять отрезки в порядке предложения, начиная с первого.
- [Кнопки в тексте мешают читать предложение] → Оформление ненавязчивое (пунктир), крупных обводок нет. Проверяется на телефоне в e2e и на снимке экрана.

## Migration Plan

Разметка добавляется в исходники без переноса данных. Старые пакеты, снимки синхронизации и копии не содержат `glosses` и читаются как прежде. Откат — удалить разметку из исходников и пересобрать контент: ревизии вернутся, слова переустановятся.
