# Дизайн: понимание на слух

## Context

См. proposal.md — Why. Типы заданий перечислены в `ORDER` (`src/domain/learning.ts`), доступность считает `availableTypes` по флагам `SkillContext`, выбор — `chooseTypeFor` по сводке навыков. Варианты ответа собирает `optionsFor(word,pool,type,random)`: для `recognition` ключ — русский перевод, для `listening` — греческое написание. Пул вариантов для понимания на слух уже есть — это варианты узнавания.

## Goals / Non-Goals

- Goal: проверять связку «звук → значение» отдельным навыком, чтобы планировщик видел её слабость отдельно от узнавания формы.
- Non-Goal: менять аудирование. «Что прозвучало?» остаётся проверкой формы на слух.
- Non-Goal: записывать аудиофайлы. Тип работает на том же источнике звука, что и аудирование; без озвучки он просто недоступен.

## Decisions

### Имя и место в порядке

Тип называется `comprehension` — имя описывает проверку, а не навык, как и остальные. В `ORDER` встаёт последним: непроверенные навыки выбираются по порядку, и понимание на слух должно идти после того, что доступно новому слову.

### Условие открытия

`comprehensionUnlockedFor(skills)` — среди последних ответов узнавания есть хотя бы один верный. Это слабее правила письма (две чистые сборки) намеренно: цель не в строгости, а в том, чтобы к незнакомому звуку не предлагали выбор из четырёх переводов. Ошибка в понимании на слух условие не сбрасывает: навык уже открыт, а слабость planner увидит по доле ошибок.

### Доступность

Флаг контекста `canComprehend` = есть озвучка (файл или голос) и четыре различных перевода. Для слова переводы берутся из пула слов, для фразы — из пула фраз. Флаг считается там же, где `canListen` и `hasOptions`, и не меняет их смысл.

### Ступень проще

`EASIER.comprehension=['recognition']`: тот же вопрос о значении, но с написанием на экране — поддержанная попытка, а не повторный экзамен. Условие открытия к попытке не применяется, как и у письма.

### Экран

Компонент `Comprehension` повторяет устройство `Listening`: большая кнопка повтора, автозапуск под общей настройкой, панель отказа с «Повторить» и «Продолжить без аудио». Отличия — вопрос «Что это значит?», варианты-переводы и блок `after`, который `Choice` показывает только после ответа: греческое написание, транскрипция и кнопка повтора.

## Risks / Trade-offs

- Пятый тип растягивает историю навыков: каждый конкретный выпадает реже. Смягчено условием открытия — на новых словах типа ещё нет.
- Для слова, чей перевод совпадает с переводом другого слова, четырёх различных вариантов может не быть — тогда тип недоступен, как и узнавание.
