# Ближайшее занятие первым

## Почему хвост уступает

Сейчас `makePlan` внутри курса собирает очередь так: хвост прошедших занятий, потом слова предстоящих уроков по дате, потом остальное. Логика была в том, что слово прошедшего занятия просрочено уже сейчас. На поставке это оборачивается каскадом: 33 нетронутых слова пройденного 1.1 при пределе 10 занимают три с лишком дня, к 1.2 не вводится ничего, в день занятия 1.2 сам уходит в хвост и так же перекрывает 1.3.

Ближайшее занятие — единственный срок, который ещё можно успеть. Хвост же никуда не торопится: его слова уже прошли мимо своей даты, и разница между «ввести сегодня» и «ввести через неделю» для них не решающая. Поэтому порядок внутри курса меняется на: `dated` (предстоящие по возрастанию даты), затем `overdue` (хвост), затем остальные уроки курса, затем для локального курса скан словаря. Разделение очередей курсов по ближайшему сроку и обрезка бюджетом не меняются.

## Счётчики срока без хвоста

`DeadlinePlan.newLeft` берётся из `seen.size` после обработки урока, и раньше в нём сидел хвост, потому что он проходился первым. Раз предстоящие теперь идут раньше, `seen.size` в момент записи срока содержит только слова предстоящих уроков со сроком не позже даты — ровно то, что нужно вводить к этой дате. Хвост в темп не попадает и не даёт ложной тревоги «предела не хватает», когда к самому занятию слов немного.

## Откуда слово

Чтобы подписать новое слово в занятии, план запоминает источник каждого нового слова: `CoursePlan.origins` и `DailyPlan.origins` — сопоставление идентификатора слова с `{lessonId,title,past}`. Слово, добранное сканом словаря, источника не имеет. `makeSession` переносит источник в элемент занятия необязательными полями `lessonTitle` и `lessonPast` только для новых слов. Элемент хранится в IndexedDB как JSON внутри сессии, поэтому схема Dexie не меняется; старые активные сессии читаются без подписи.

`Introduction` получает элемент, а не только слово, и показывает приглушённую строку: «К уроку N» для предстоящего урока и «Хвост урока N» для прошедшего, где N — `shortTitle` названия урока. Без урока строка не рендерится.

## Текст на «Сегодня»

Блок хвоста обещал «берём их в «Новые» первыми». Теперь он говорит, что хвост добирается после слов ближайшего занятия: иначе экран противоречил бы тому, что пользователь увидит в занятии.

## Эталон планировщика

Порядок новых слов и счётчики сроков в сценариях с прошедшим уроком (`mixed`) меняются, поэтому эталон `tests/fixtures/plan-golden.json` перезаписывается и сверяется по diff: другие сценарии и поля должны остаться прежними.
