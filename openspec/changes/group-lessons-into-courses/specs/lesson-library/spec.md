## ADDED Requirements

### Requirement: Уроки сгруппированы по курсам

Каждый урок SHALL принадлежать курсу: поставляемый — своему курсу из каталога, созданный пользователем и полученный импортом — локальному курсу «Мои слова». Локальный курс SHALL создаваться приложением, SHALL не обновляться из каталога и SHALL сохраняться при обновлении каталога. Список уроков SHALL группироваться по курсам с названием, источником, числом уроков и слов и состоянием курса. Разбиение существующих уроков по курсам SHALL выполняться без сети: по сохранённому пакету урока, а урок без пакета SHALL попадать в локальный курс.

#### Scenario: Свой набор
- **WHEN** пользователь создаёт набор вручную или импортирует слова из Quizlet
- **THEN** набор появляется в курсе «Мои слова» и не участвует в обновлении из каталога

#### Scenario: Переход на курсы без сети
- **WHEN** приложение с уже установленными уроками впервые открывается после обновления и сети нет
- **THEN** уроки разложены по курсам по своим пакетам, созданные вручную — в «Мои слова», прогресс и даты сохранены

#### Scenario: Курс уже учат
- **WHEN** при переходе на курсы у курса есть хотя бы один установленный урок
- **THEN** курс считается подписанным и его обновления приходят без дополнительного действия
