## Why

Иллюстраций уже 189, и все они нарисованы «на глаз»: 459 уникальных цветов на 189 файлов, подложки от голубой до кремовой с двадцатью оттенками кремового, размеры от 300 байт до 1,9 КБ. Формат при этом сложился одинаковый — `viewBox="0 0 320 220"`, плоские фигуры, цветный прямоугольник во всю картинку — но записан он только в голове у рисующего. Публикация проверяет одно: в картинке нет `<text>`. Следующие наборы добавят ещё столько же картинок, и без писаного стандарта и проверки, которая его держит, разнобой удвоится.

Расхождения заметнее всего на абстрактных словах — чувствах, глаголах, признаках: «радость» и «смех» легко нарисовать одинаково, а тест на побайтовую уникальность этого не увидит. Картинку пользователь видит и в момент ответа, поэтому она не должна ни выдавать ответ, ни отвлекать.

## What Changes

- Появляется писаный стандарт иллюстрации (`docs/art-standard.md`): холст и `viewBox`, подложка, палитра с именованными ролями, правила композиции, правила для абстрактных слов, потолок размера, запрет текста, скриптов, растра, внешних ссылок и анимации.
- Палитра становится данными (`content/art/palette.json`): один источник, из которого читают проверка публикации, документ стандарта и обзорный лист. Порядка двадцати цветов вместо 459, выбранных из самых частых уже существующих.
- Публикация проверяет каждую SVG-иллюстрацию: размер не больше 3 КБ, `viewBox` ровно `0 0 320 220`, нет текста, скриптов, стилей, анимации, растровых вложений и внешних ссылок, все цвета из палитры. Нарушение — ошибка публикации с именем файла и причиной, как у остальных проверок контента.
- Существующие картинки вне палитры перечислены в `content/art/legacy.txt`. Для них проверка палитры не блокирует публикацию, остальные проверки действуют. Список только сокращается: имя, которого нет в `art/`, и файл, который уже в палитре, — ошибка публикации; новых имён в список не добавить без правки теста. `npm run content` печатает, сколько файлов ещё вне палитры.
- Обзорный лист `docs/art-sheet.html` получает легенду палитры и подсветку файлов вне палитры с их чужими цветами.
- Перерисовка 187 существующих картинок под палитру — последующая работа, не блокирующая это изменение; она вынесена в задачи как отдельный пункт.

Вне этого изменения: сами SVG не меняются, тест на побайтовую уникальность не расширяется до проверки сходства (открытый вопрос в design.md), клиент картинки по-прежнему показывает через `<img>` и не различает контексты.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `greek-word-content`: иллюстрация к слову подчиняется стандарту — один объект, палитра, без текста и отсылок к переводу, без движения; для абстрактных слов — различимая композиция.
- `content-delivery`: публикация проверяет иллюстрации по стандарту и ведёт список унаследованных файлов вне палитры.

## Impact

Затрагиваются публикация контента (`content/build.ts`), тесты контента, обзорный лист, документация в `docs/` и README. Схема пакетов, каталог, клиент и сами 189 SVG не меняются: публикация с текущим контентом проходит, потому что все файлы вне палитры внесены в список унаследованных. Сценарии e2e не затронуты.
