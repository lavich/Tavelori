## MODIFIED Requirements

### Requirement: Начальные уроки
Приложение SHALL предоставлять исходные уроки через каталог и устанавливать их слова при открытии урока или явном скачивании. Пакет 1.1 SHALL сохранять 33 слова и статус пройденного урока без выдуманной даты; пакет 1.2 SHALL сохранять 30 слов и дату 2026-09-18. Артикли, ударения и переводы сохраняются. Поставляемое слово SHALL не нести отметок освоенности: освоенность считается только по ответам пользователя. Автоматическая установка всех 63 слов при первом запуске заменяется установкой выбранного пакета.

#### Scenario: Первый запуск
- **WHEN** пользователь впервые открывает приложение с доступной сетью
- **THEN** видит исходные уроки в каталоге, их слова загружаются только по выбору урока, история ответов пуста

#### Scenario: Установка исходных уроков
- **WHEN** пользователь устанавливает уроки 1.1 и 1.2
- **THEN** доступны исходные 63 слова без выдуманных событий обучения и без готовой освоенности

#### Scenario: Повторный запуск
- **WHEN** пользователь снова открывает приложение
- **THEN** установленные уроки доступны локально без дублирования, изменения пользователя сохраняются
