## 1. Деление на слоги

- [x] 1.1 Создать чистый модуль деления греческого слова на слоги: ядра с диграфами, синизеса безударных `ι`/`υ`, таблица сочетаний, с которых начинаются слова, деление двойных согласных; проверить точными ожиданиями сложные случаи (`δέντρο`, `μπαλκόνι`, `θάλασσα`, `παππούς`, `διαβάζω`, `βιβλίο`, `οικογένεια`).
- [x] 1.2 Обеспечить плитки со всеми токенами: артикль отдельной плиткой; проверить, что на всех 63 исходных словах объединение плиток даёт исходное написание и плиток не меньше двух.

## 2. Навык в очереди

- [x] 2.1 Добавить тип упражнения `assembly` и поставить его между выбором перевода и написанием; проверить, что непроверенная сборка выбирается раньше написания.
- [x] 2.2 Реализовать правило открытия написания по двум верным сборкам после последней ошибки в написании; проверить открытие, повторное закрытие после ошибки и обход правила для слов без слогов.
- [x] 2.3 Складывать перемешанные плитки в варианты ответа элемента сессии; проверить, что состав плиток сохраняется, а порядок отличается от правильного.

## 3. Экран упражнения

- [x] 3.1 Реализовать экран сборки: строка ответа с возвратом плитки, пул плиток, проверка только при использовании всех плиток; проверить браузерным сценарием верный и неверный порядок.
- [x] 3.2 Показать после ответа верное деление, пример с озвучкой и «Далее», скрыв плитки; проверить, что плиток после ответа не остаётся.

## 4. Результаты и приёмка

- [x] 4.2 Пройти браузерный сценарий занятия со всеми пятью упражнениями и убедиться, что событие сборки сохраняется с собранным ответом; выполнить typecheck, unit-тесты, production build и браузерные проверки.
