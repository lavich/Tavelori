## REMOVED Requirements

### Requirement: Фраза как самостоятельная карточка

**Reason**: Способность описывала фразы и пропуски вместе. Пропуски сняты, и требование про фразы продолжает жить без изменений в новой способности `phrase-content`.
**Migration**: Читать требование в `phrase-content`. Поведение фразы не меняется.

### Requirement: Один явный пропуск

**Reason**: Вид карточек «заполни пропуск» снят: разметка шаблона, канонический ответ и список допустимых ответов больше не поставляются и не хранятся.
**Migration**: Миграции нет. Карточки пропуска удаляются из локальной базы при переходе на схему 7, их исходники и записи в уроке 1.1 убраны из контента. История ответов на них сохраняется.

### Requirement: Необязательное описание учебной цели

**Reason**: Описание учебной цели существовало только у карточек пропуска и снимается вместе с видом.
**Migration**: Миграции нет. Поле пропадает из пакетов, локальных записей, снимков заданий и полной копии. Отдельной совместимости оно не требует: описание цели жило только внутри карточки пропуска, а пакет с такими карточками отклоняется целиком по неизвестному виду.

### Requirement: Проверка фразы и пропуска

**Reason**: Требование задавало одно правило проверки для двух видов. Пропуски сняты, и правило для фразы переписано под один разрешённый текст в `phrase-content`.
**Migration**: Читать требование «Проверка письменного ответа фразы» в `phrase-content`. Для фразы правило не меняется: уходит только явный список допустимых ответов и разбор целого предложения вместо пропуска.

### Requirement: Условие и обратная связь без раскрытия ответа

**Reason**: Требование целиком описывало экран задания с пропуском: шаблон, подписанное поле ввода, скрытую до ответа озвучку полного предложения и объяснение.
**Migration**: Миграции нет. Правило нераскрытия ответа до проверки для остальных заданий задано в `adaptive-learning`.
