## Why

Lexi уже имеет мобильный веб-интерфейс, но для тренировки пользователь должен открывать отдельный браузер или PWA. Telegram Mini App позволит запускать те же уроки из профиля бота и проверить удобство обучения внутри Telegram без разработки второго интерфейса.

## What Changes

- Добавить запуск существующего приложения как Main Mini App через профиль `@TaveloriBot` и прямую ссылку `https://t.me/TaveloriBot?startapp`, сохранив обычный браузерный режим.
- Адаптировать навигацию назад, размеры окна, безопасные отступы, тему и жизненный цикл тренировки к Telegram. Сохранить общие компоненты Lexi и текущие разделы; добавить отключаемый тактильный отклик и проверить нативное главное действие на экране «Сегодня» в прототипе.
- Сохранить локальную базу для офлайн и добавить синхронизацию компактного прогресса, настроек и расписания через Telegram CloudStorage между двумя устройствами одного аккаунта. Стандартные уроки и медиа загружаются из каталога; полный перенос пользовательских данных остаётся через копию.
- Веб и Telegram используют независимый прогресс: веб хранит его только в текущем браузере, Telegram синхронизирует свой компактный прогресс через CloudStorage. Веб-вход через Telegram и автоматический обмен между режимами не добавляются; ручной перенос копией сохраняется.
- Обрабатывать ограничения WebView для аудио, файлов и офлайн без ложного подтверждения успешного действия.
- Выделить адаптер синхронизации для будущего внешнего хранилища; сначала проверить CloudStorage, файлы, звук и клавиатуру минимальным прототипом на двух устройствах. Внешняя база сейчас не подключается.
- Подготовить инструкцию возможной смены адреса с ручным переносом локальной базы, без фактического переезда.
- Подготовить инструкцию настройки BotFather и матрицу проверок Telegram на iOS и Android.

Предлагаемый объём — первый этап из исследования: Mini App без сервера. Автоматическое объединение независимых тренировок, синхронизация вне Telegram, авторизация на сервере, сообщения-напоминания, платежи и производство аудиопакета в это изменение не входят. Их можно спроектировать отдельно после проверки первого этапа.

## Capabilities

### New Capabilities

- `telegram-mini-app`: запуск, интеграция с оболочкой Telegram, сохранность локального обучения, облачный прогресс одного Telegram-аккаунта и совместимость с мобильными клиентами.

### Modified Capabilities

- `local-first-app`: уточнить границы офлайн-гарантии для Telegram и загрузки уроков по запросу, сохранив гарантию офлайн-запуска браузерной PWA.

## Impact

Затрагиваются `src/main.tsx`, новый адаптер Telegram, `src/app`, стили оболочки и занятия, `src/shared/audio.ts`, `src/shared/offline.ts`, экспорт/импорт в `src/features/backup`, браузерные тесты и документация. Используется официальный JavaScript bridge Telegram с проверкой доступности функций. React, Vite, GitHub Pages, алгоритмы обучения сохраняются. Добавляются локальные метаданные синхронизации и разделение профилей; совместимость старых копий сохраняется. Токен бота не попадает в клиент, репозиторий или сборку. Внешняя настройка бота потребуется при выпуске; создание плановых артефактов её не выполняет.
