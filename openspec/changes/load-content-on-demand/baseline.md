# Базовые замеры до изменения

Зафиксировано на коммите `317c27d` (main), `npm run build`, Vite 8.3, Node 24.9.

## Размер сборки

| Файл | Байт | gzip |
| --- | --- | --- |
| `assets/index-*.js` | 806 736 | 257 080 |
| `assets/index-*.css` | 70 751 | 12 920 |
| `assets/workbox-window-*.js` | 5 653 | 2 200 |
| `dist/` целиком | ~904 КБ | — |

Словарь внутри стартового JS: исходные слова, разбор чтения, примеры и все 63 SVG-иллюстрации занимают
непрерывный участок примерно **42 900 байт** минифицированного кода (около 5 % чанка). Каждое новое слово
с иллюстрацией добавляет к стартовому JS ~650 байт; отдельного чанка контента нет.

## Сетевой профиль запуска

Precache Workbox: 8 записей, 864 КБ. Список: `index.html`, `404.html`, `manifest.webmanifest`, `icon.svg`,
`assets/index-*.js`, `assets/index-*.css`, `assets/workbox-window-*.js`. Всё содержимое словаря и медиа
приходит в первом же запросе JS и целиком попадает в precache; при обновлении любого слова
перекачивается весь чанк приложения.

При запуске приложение делает `ensureSeed()` — пишет все 127 слов, 4 урока и 63 иллюстрации в IndexedDB —
и `loadSnapshot()` читает целиком таблицы `words`, `lessons`, `states`, `events`, `sessions` для каждого
экрана через `useSnapshot()`.

## Сценарии планировщика

Эталонные результаты `makePlan` и `makeSession` на четырёх синтетических наборах записаны в
`tests/fixtures/plan-golden.json` тестом `tests/plan-golden.test.ts`:

- `mixed` — 40 слов, два удалённых, общее слово в двух датированных уроках, недатированный и проведённый
  уроки, слова вне уроков, повторения в состояниях Relearning/Learning/Review, введённые сегодня слова,
  история навыков для выбора упражнения (в том числе закрытое написание после ошибки);
- `budgetExhausted` — дневной лимит уже исчерпан;
- `noDated` — только недатированный урок и слова вне уроков;
- `smallDict` — три слова, недостаточно вариантов ответа.

Для каждого набора зафиксированы план (очередь новых, повторения, сроки, темп) и три сессии: обычная,
с системным голосом и ручная тренировка, при фиксированном источнике случайности.
