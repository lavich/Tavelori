## Синтетический масштаб (`tests/scale.test.ts`)

Каталог из 3000 уроков на 102 000 слов читается одним запросом и не создаёт ни слов, ни пакетов, ни прогресса.

Локальная база: 100 000 слов (1031 удалено), 20 000 состояний, 60 000 ответов, 200 уроков. Счётчик хука
`reading` Dexie показывает прочитанные записи каждой таблицы:

| Операция | words | events | sessions | states |
| --- | --- | --- | --- | --- |
| Первая страница словаря (50 карточек) | ≤ 52 | 0 | 0 | 50 |
| Поиск по префиксу (страница из 50) | ≤ 52 (ключи индекса без карточек до чтения страницы) | 0 | 0 | 50 |
| План дня (10 новых, 13 000+ срочных) | 0 | 0 | 0 | < 20 000 |
| Сессия из 20 упражнений | ≤ 20 + пул вариантов 48 (дважды) | только история слов сессии | 0 | по словам сессии |
| Запись ответа | 0 | ≤ 1 | 1 | ≤ 1 |
| Статистика | 0 | 7 дней + 5×10 последних по навыкам | 0 | все состояния порционно |
| Список уроков с числом новых | 0 | 0 | 0 | по связям уроков |

Весь набор на fake-indexeddb укладывается в 13 секунд.

## Эквивалентность планирования

`tests/plan-golden.test.ts` хранит результаты `makePlan`/`makeSession` старой реализации на четырёх сценариях
(`tests/fixtures/plan-golden.json`). Новый планировщик воспроизводит их на снимке в памяти, а `tests/queries.test.ts`
подтверждает совпадение результатов между Dexie и снимком при одинаковых данных и источнике случайности, включая
слово в нескольких уроках, удалённые слова, ограничения новых слов, доступность упражнений, состав вариантов и статистику.

## Миграция, обновление и копии

- Профиль первой схемы: `wordIds` → связи с порядком, исходные уроки отмечены `legacy`, прогресс, история, удаления и
  правки сохранены, индексы поиска построены, сети нет (`tests/migration.test.ts`).
- Первое обновление после миграции заменяет нетронутые слова, сохраняет отредактированные и удалённые и сообщает конфликты.
- Общее слово двух уроков — одна запись и две связи; убранная пользователем связь не восстанавливается обновлением.
- Повреждённый, несовместимый, чужой пакет и ошибка записи (в том числе нехватка места) не оставляют частичного урока и
  не трогают установленную версию; одновременные запросы одного пакета объединяются.
- Копия схемы 2 включает связи, медиа и метаданные пакетов, каталог исключён; копия схемы 1 мигрирует в промежуточной базе;
  повреждённая копия, копия новее приложения и копия с битыми связями отклоняются до замены данных.

## Браузерные сценарии (Playwright, production build, 20 сценариев)

Все прежние сценарии переведены на установку уроков из каталога через открытие урока. Добавлено: «Скачать для офлайн»
показывает «Медиа: 30 из 30» только после фактической загрузки, скачанный урок работает без сети после закрытия страницы,
а неустановленный урок без сети показывает «Пакет не загружен» и «Повторить загрузку» вместо пустого урока.
