## Why

Слово нельзя показать другому человеку: ссылка `t.me/<бот>` всегда открывает «Сегодня», а маршрут `/words/:id` работает только для слов, уже установленных в локальную базу. Ссылка на конкретное слово нужна и для того, чтобы делиться им, и для быстрой проверки карточки на чистом устройстве или в dev-боте.

## What Changes

- Сборка контента добавляет в каждую запись каталога список идентификаторов слов урока (`wordIds`). Поле необязательное: прежние клиенты его не читают, версия схемы не меняется.
- Новый маршрут `/share/word/:id`: если слово есть в локальной базе — переход на обычный экран слова; иначе урок находится по каталогу, его пакет читается в память, и карточка показывается только для просмотра. Ни урок, ни подписка на курс, ни медиа в базу не записываются.
- Запуск Mini App с параметром `startapp=w_<id>` один раз за запуск ведёт на `/share/word/<id>`.
- Кнопка «Поделиться» на экране слова для слов, которые есть в каталоге: в Telegram открывает системный выбор чата со ссылкой на бота, в браузере — Web Share или копирование ссылки.
- Существующие идентификаторы слов (`w34-03`) не меняются: они уже латинские и короткие, а на них завязаны прогресс, синхронизация и резервные копии.

## Capabilities

### New Capabilities
- `word-sharing`: ссылка на слово через бота, просмотр слова из неустановленного урока без записи в базу, индекс слов в каталоге и кнопка «Поделиться».

## Impact

- `content/build.ts`, `src/content/schema.ts` — поле `wordIds` в записи каталога и его разбор.
- `src/content/client.ts` — чтение пакета без установки и поиск урока по слову.
- `src/app/App.tsx`, `src/platform/launch.ts` — маршрут `/share/word/:id` и однократный переход по `start_param`.
- `src/features/words/` — экран просмотра, кнопка «Поделиться»; `WordArt`/`SpeakButton` получают вариант с прямым URL медиа.
- Каталог вырастает примерно на 5 КБ; новых зависимостей нет.
