## Context

Мотивация — в proposal.md, требования — в `specs/word-sharing/spec.md`.

- Идентификаторы слов задаются в YAML явно (`id: w34-03`), у всех 413 слов они латинские и не длиннее 6 символов, поэтому помещаются в `startapp` (не больше 64 символов из `A-Za-z0-9_-`).
- Каталог (`content/catalog.json`) содержит только метаданные уроков. Сопоставления «слово → урок» в нём нет. `parseCatalog` пропускает незнакомые поля, поэтому новое поле старые клиенты не заметят.
- При старте `main.tsx` вызывает `refreshCatalog()`: записи каталога сохраняются в `db.catalog`, метаданные курсов — в `db.courses`. Так было и раньше, эта функция ничего не меняет в этом шаге.
- `installLesson` устанавливает пакет и включает подписку на курс. `ensureAsset` скачивает медиа и сохраняет их в `db.assets`. Оба пути пишут в базу, поэтому для просмотра не подходят.
- `start_param` читается в `launchContext()`. `LaunchContext` кэшируется в `sessionStorage`, при перезагрузке WebView Telegram передаёт те же параметры снова.
- Mini App открывается как Main Mini App бота, ссылка `https://t.me/<бот>?startapp=<param>`. Имя бота задаёт `launch.bot`, для dev-бота это `?bot=TaveloriDevBot`.

## Goals / Non-Goals

**Goals:**
- Одна точка входа `/share/word/:id` для браузера, Playwright и Telegram.
- Просмотр неустановленного слова без побочных записей в базу.

**Non-Goals:**
- Ссылки на фразы и уроки. Префикс `w_` оставляет место для `p_`/`l_` позже.
- Ссылки на упражнения и отладочный экран `/debug`.
- Передача правок пользователя: ссылка всегда ведёт на версию курса.
- Превью ссылки в чате (inline-режим бота, `savePreparedInlineMessage`). Для них нужен сервер бота.

## Decisions

**1. Индекс `wordIds` в записи каталога вместо нового кода слова или хэша.**
Идентификаторы уже подходят для `startapp`. Отдельный код дублировал бы id, а менять id означало бы мигрировать прогресс (`unitKey`), синхронизацию и резервные копии. Разбирать урок из префикса `w34` ненадёжно: одно слово может входить в несколько уроков, а у `lesson-1-1-extra` префикс не совпадает с id урока. Слово из нескольких уроков сопоставляется первому уроку по порядку каталога.

**2. Поиск по `db.catalog` перебором, без нового индекса Dexie.**
Уроков десятки, `toArray()` занимает миллисекунды. Индекс `*wordIds` потребовал бы восьмой версии схемы базы. `CatalogEntry.wordIds` хранится как необязательное поле: `bulkAdd` сохраняет его без изменения схемы.

**3. Чтение пакета без установки: `previewPackage(lessonId)` в `content/client.ts`.**
Функция берёт запись из `db.catalog`, получает пакет через `source.json(entry.url)`, проверяет его `parsePackage` и возвращает `PackageWord` и медиа из пакета. В базу она ничего не пишет. Пакет кэшируется в памяти на время вкладки. HTTP-кэш и Service Worker по-прежнему обслуживают неизменяемый URL.
Отвергнуто: временная установка с последующим удалением. Её прерывание оставило бы в базе мусор и подписку на курс.

**4. Источник медиа через React-контекст.**
`WordArt` и `SpeakButton` получают картинку и звук через контекст `AssetSource`. По умолчанию он работает как сейчас (`ensureAsset`). Экран просмотра подставляет источник, который по `imageAssetId`/`audioAssetId` находит `url` в `pack.media` и отдаёт `import.meta.env.BASE_URL + url` напрямую, без записи в `db.assets`. `PackageWord` приводится к `Word` для отображения тем же преобразованием, которым пользуется `mergeWord`, но без сохранения.
Отвергнуто: отдельные компоненты карточки для просмотра. Они разошлись бы с основной карточкой.

**5. Маршрут `/share/word/:id` — отдельный экран `SharedWordScreen`.**
1. Слово есть в `db.words` и не удалено → `navigate("/words/:id", { replace: true })`.
2. Слова нет, каталог в базе пуст (первый запуск, `refreshCatalog` ещё не завершился) → экран ждёт каталог через `useLiveQuery`. Если каталог не появился за 10 секунд, выводится сообщение о сбое загрузки.
3. Урок найден → `previewPackage`, затем карточка только для просмотра: без «Потренировать» и «Редактировать», с плашкой «Слово из урока <название>», которая ведёт на `/lessons/:lessonId`.
4. Урок не найден → «Слово не найдено». Пакет не загрузился → сообщение с кнопкой «Повторить».

**6. Однократный `start_param`.**
`startRoute(launch)` превращает параметр вида `w_<id>` (где id подходит под `^[A-Za-z0-9-]{1,60}$`) в путь `/share/word/<id>`, на остальное возвращает `null`. `App` при монтировании один раз делает `navigate(path, { replace: true })`. После этого в `sessionStorage` ставится метка `lexi:start-consumed`, и перезагрузка WebView переход не повторяет. Через `replace` назад ведёт на «Сегодня», потому что история пуста и `useGoBack` так и работает.

**7. Кнопка «Поделиться».**
Ссылка `https://t.me/${launch.bot}?startapp=w_${id}`. В Telegram — `WebApp.openTelegramLink("https://t.me/share/url?url=…&text=…")`. В WebApp нет отдельного метода «поделиться ссылкой», а `openTelegramLink` поддерживается с версии 6.1. В браузере — `navigator.share({ url, text })`, при его отсутствии или ошибке, кроме `AbortError`, — `navigator.clipboard.writeText` и `toast.success("Ссылка скопирована")`. Кнопка видна, если id слова есть в `wordIds` какой-либо записи каталога. Используется тот же поиск, что и в решении 2.

## Risks / Trade-offs

- [Слово переехало в другой урок] → ссылка продолжает работать: урок ищется по актуальному каталогу, а не хранится в ссылке.
- [Каталог старой сборки без `wordIds` закэширован у пользователя] → кнопка скрыта, ссылка показывает «Слово не найдено» до обновления каталога. Это ухудшение без поломки.
- [Размер каталога] → около 413 × 10 байт ≈ 5 КБ без сжатия, до сжатия. Ограничение `check:bundle` каталога не касается.
- [Главный Mini App бота не настроен в BotFather] → `?startapp=` откроет чат с ботом, а не приложение. Нужно проверить на `TaveloriDevBot` до выпуска.
- [Медиа просмотра не попадают в офлайн-кэш базы] → это осознанно. Без сети просмотр показывает сбой загрузки.

## Migration Plan

Новая версия базы не нужна. Контент пересобирается вместе с приложением, и новый каталог с `wordIds` публикуется тем же деплоем. Откат — прежний деплой: поле без клиента безвредно, а клиент без поля скрывает кнопку.
