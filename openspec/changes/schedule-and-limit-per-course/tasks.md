## 1. Модель и миграция

- [ ] 1.1 Добавить курсу расписание, дневной лимит и язык; убрать расписание и лимит из настроек приложения.
- [ ] 1.2 Перенести версией базы 5 общее расписание и лимит в каждый курс; проверить, что даты уроков и дневной темп после перехода не изменились.
- [ ] 1.3 Проставлять язык курса при публикации и требовать один язык на курс; проверить отказ для курса со смешанными языками.

## 2. Даты уроков

- [ ] 2.1 Раскладывать даты по расписанию внутри курса, а не одной общей цепочкой; проверить два курса с разными днями, урок с собственной датой и урок без курса.
- [ ] 2.2 Перевести закрепление прошедших уроков на расписание курса; проверить, что урок закрывается по своей дате.

## 3. Планировщик

- [ ] 3.1 Считать дневной бюджет по каждому курсу; проверить, что слово из двух курсов вводится один раз и засчитывается обоим.
- [ ] 3.2 Сливать очереди курсов по ближайшему сроку и обрезать каждую своим бюджетом; проверить порядок при разных сроках и курс без даты.
- [ ] 3.3 Считать требуемый темп и нехватку лимита по курсу; проверить, что предупреждение называет курс, а курс без срока не создаёт ложной тревоги.
- [ ] 3.4 Оставить очередь повторений общей; проверить, что слово из двух курсов не повторяется дважды за день.

## 4. Синхронизация

- [ ] 4.1 Возить курсы в компактном снимке и убрать из него расписание и лимит настроек; проверить перенос на второе устройство и чтение снимка прежнего формата без затирания локальных значений.
- [ ] 4.2 Уточнить формулировку о составе снимка в незакрытом изменении `add-telegram-mini-app`, чтобы спека не расходилась с кодом.

## 5. Экраны

- [ ] 5.2 Убрать поле «новых слов в день» из общих настроек; проверить, что остальные настройки сохраняются как прежде.
- [ ] 5.3 Показать на «Сегодня» общее число новых с разбивкой по курсам и предупреждение с названием курса; проверить один курс, два курса и отсутствие новых.
