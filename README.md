# Lexi — греческий к каждому занятию

Личный тренажёр греческих слов: наборы с датой занятия, карточки с картинкой, IPA и разбором чтения,
четыре типа упражнений и интервальные повторения FSRS. Всё работает локально, без регистрации и сервера.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # production build
npm run preview    # запуск собранного приложения
npm test           # unit и integration тесты (Vitest)
npm run test:e2e   # браузерные проверки по production build (Playwright, Chromium)
```

## Что уже есть

- **Исходные наборы.** Урок 1.1 (33 слова) и урок 1.2 (30 слов, дата 18 сентября 2026) загружаются один раз;
  удалённые слова не восстанавливаются при обновлении приложения.
- **Карточка слова.** Собственная иллюстрация, IPA, объяснение ударения, интерактивный разбор буквосочетаний
  и пример употребления с переводом; слово и предложение озвучиваются.
- **План дня.** Накопительный темп по всем ближайшим датам, дневной лимит новых слов, очередь
  relearning → просроченные → сегодняшние.
- **Занятие.** Знакомство, «вспомни слово» с самооценкой, выбор перевода, аудирование, сборка слова
  из слогов и написание с посимвольной обратной связью. Ответ сохраняется атомарно: двойное нажатие
  и вторая вкладка не портят историю.
- **Ступень перед письмом.** Слово сначала собирается из перемешанных слогов (артикль — отдельная плитка),
  написание от руки открывается после двух чистых сборок; ошибка в написании снова требует двух сборок.
  Деление на слоги считается по правилам новогреческого, см. `openspec/changes/add-syllable-assembly-exercise/`.
- **Ручная тренировка** слова или набора в режиме practice — навык фиксируется, интервалы FSRS не сдвигаются.
- **Слова и уроки.** Поиск, фильтры по набору и состоянию, редактор слова, примеры, загрузка своей картинки и аудио,
  мягкое удаление, создание наборов и перенос даты.
- **Импорт Quizlet** (чередование строк и TSV) с предпросмотром, дубликатами и транзакционным сохранением.
- **Статистика** за 7 дней, сроки, состояние словаря и доля успешных ответов по навыкам с числом попыток.
- **Офлайн и копии.** PWA precache, хранение в IndexedDB, полный экспорт/восстановление с проверкой файла
  и отдельный TSV-экспорт слов.

## Известные ограничения

- **Аудио.** Локальных аудиофайлов для 63 исходных слов нет: озвучка идёт системным греческим голосом (`el-GR`),
  а при его отсутствии аудирование честно отключается. Свой файл можно загрузить в редакторе слова —
  он сохраняется в базу и попадает в полную копию.
- **Фонетика.** IPA и разборы чтения подготовлены по правилам чтения стандартного новогреческого и проверены
  вручную, но не сверены со словарными изданиями построчно. Пользовательские правки IPA помечаются непроверенными.
- **Иллюстрации.** Это собственные векторные рисунки, а не фотографии; для абстрактных слов нарисованы ситуации.
- **Примеры употребления.** Составлены для Lexi на стандартном новогреческом. Предложение можно прослушать системным греческим голосом; записанных аудиофайлов для примеров нет, без голоса кнопка отключена.
- Кипрская диалектная норма не поддерживается — используется стандартный новогреческий.
- Синхронизация между устройствами, аккаунты и распознавание речи в эту версию не входят.

## Интерфейс

Компоненты — [shadcn/ui](https://ui.shadcn.com) (базовый реестр, примитивы Base UI) поверх Tailwind CSS v4.
Исходники компонентов лежат в `src/components/ui` и правятся под наш макет: у Button добавлены размеры
`xl`/`md` и варианты `soft`/`quiet`, у Card — отступы и скругление Lexi, у Badge — вариант `soft`,
у Alert — `warning`. Палитра Lexi задана токенами shadcn в `src/styles.css`, поэтому компоненты реестра
сразу выглядят как остальное приложение.

CSS-модули остались там, где компонента-аналога нет: раскладка экрана (`shared/ui.module.css`),
карточка слова (`shared/word.module.css`), нижняя навигация и шапка, а также экран занятия
с закреплённым доком (`features/learning/session.module.css`).

ReUI рассматривался как реестр компонентов: подключается тем же CLI, но Button, Card, Input, Select,
Progress и остальные его компоненты отдаются только по платному ключу `REUI_LICENSE_KEY` — бесплатны
лишь Badge и Alert. Поэтому используется базовый реестр shadcn.

## Структура

```
src/domain        чистая логика: типы, импорт, календарь, план, FSRS-адаптер, написание, статистика
src/storage       Dexie: схема, однократный seed, транзакционные операции
src/content       исходные 63 слова, разбор чтения, примеры и векторные иллюстрации
src/components/ui компоненты shadcn/ui, подогнанные под макет
src/features      экраны: сегодня, уроки, слова, занятие, статистика, импорт, копия
src/shared        часы, формат, аудио, медиа-валидация, офлайн-статус
```
