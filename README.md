# Lexi — греческий к каждому занятию

Личный тренажёр греческого: наборы по расписанию занятий, карточки трёх видов — слово, фраза и задание
«заполни пропуск», — упражнения на узнавание, сборку, аудирование, написание и ввод пропущенной формы,
интервальные повторения FSRS. Всё работает локально, без регистрации и сервера.

Приложение: **https://tavelori.app/** — публикуется автоматически из `main` через GitHub Pages (custom domain репозитория `lavich/Tavelori`).

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # production build
npm run preview    # запуск собранного приложения
npm test           # unit и integration тесты (Vitest)
npm run test:e2e   # браузерные проверки по production build (Playwright, Chromium)
```

Ветка `main` защищена: изменения попадают в неё только через pull request после зелёного job `checks`
(`.github/workflows/ci.yml`: `typecheck`, `test`, `spec`, `build`, `test:e2e`). Прямой push и force-push запрещены.

## Что уже есть

- **Каталог и уроки по запросу.** При запуске приложение получает только оболочку и небольшой каталог
  (`content/catalog.json`); словарь в стартовый JavaScript и precache не входит. Урок 1.1 (33 слова),
  урок 1.2 (30 слов, дата 18 сентября 2026) и уроки 1.3 и 1.4 показаны в каталоге и загружаются при
  открытии урока одним пакетом; картинки и аудио подгружаются при просмотре, а «Скачать для офлайн»
  забирает все обязательные медиа урока и проверяет их наличие. Установка транзакционная, повторные
  запросы объединяются, повреждённый или несовместимый пакет отклоняется без частичного урока.
- **Обновление контента без потери правок.** У поставленных слов хранится ревизия и признак локальной
  правки; новая версия пакета заменяет нетронутые записи, а отредактированные, удалённые слова и убранные
  из урока связи сохраняются, о конфликтах сообщается. Идентификаторы и прогресс не меняются.
- **Карточки трёх видов.** Слово, фраза целиком и задание с одним пропуском. У каждой карточки свой прогресс
  повторений: знание перевода слова не засчитывает правильную форму в предложении, а два пропуска одного
  предложения независимы. Фразы изучаются узнаванием, написанием и доступным аудированием (варианты подбираются
  среди фраз, слоговой сборки у них нет); пропуск проверяется вводом скрытой формы. Фраза без перевода и озвучки
  остаётся справочной: она видна в уроке с подписью «Нет доступного упражнения» и не занимает дневную квоту.
  Экран урока показывает группы «Слова», «Фразы», «Заполни пропуск», просмотр карточек и тренировку группы;
  раздел «Слова» остаётся словарём слов.
- **Исходники контента в YAML.** Одно слово — один файл с греческим именем (`content/words/το-σπίτι.yaml`),
  фраза — `content/phrases/<id>.yaml`, задание с пропуском — `content/clozes/<id>.yaml`,
  урок — список идентификаторов (`words`) или упорядоченный смешанный состав (`items`) в `content/lessons/`,
  иллюстрации — `content/art/το-σπίτι.svg`. Поле `id` внутри
  файла хранит стабильный идентификатор; у нового слова его можно не указывать. `npm run content` (вызывается
  сам перед `dev` и `build`) проверяет исходники и собирает каталог, версионированные пакеты и медиа в
  `public/content`. Иллюстрации подчиняются стандарту `docs/art-standard.md`: холст `320×220`, палитра из
  `content/art/palette.json`, не больше 3 КБ, без текста, скриптов, растра и анимации; нарисованные до стандарта
  файлы перечислены в `content/art/legacy.txt`, и этот список только сокращается.
- **Расписание занятий.** На экране «Уроки» задаются день первого занятия и дни недели; предстоящие наборы
  без своей даты получают дни расписания по порядку номеров в названии («1.9» < «1.10» < «2.1»). Дата,
  заданная на экране урока, становится якорем и сдвигает следующие наборы; её можно вернуть в расписание.
  Урок, чей день прошёл, при запуске и при смене дня закрепляется проведённым со своей датой, поэтому
  изменение расписания не трогает прошедшие занятия.
- **Карточка слова.** Собственная иллюстрация, IPA, объяснение ударения, интерактивный разбор буквосочетаний
  и пример употребления с переводом; слово и предложение озвучиваются.
- **План дня.** Накопительный темп по всем ближайшим датам, дневной предел новых карточек курса
  (`newItemsPerDay`; прежний предел новых слов перешёл в него с тем же числом), очередь
  relearning → просроченные → сегодняшние. Одна карточка любого вида — одна единица бюджета.
- **Занятие.** Знакомство, выбор перевода, аудирование, сборка слова из слогов, написание с посимвольной
  обратной связью и ввод пропущенной формы. До ответа в пропуске видны только предложение с пробелом,
  поле ввода и подсказка на русском: правильная форма, полное предложение, объяснение и озвучка появляются
  после сохранённого ответа. Проверка фразы и пропуска отдельная от словарной: сравниваются все точные
  варианты, затем варианты без знака ударения («Почти»); артикль, отрицание, предлог, форма и пунктуация
  не прощаются. Ответ сохраняется атомарно: двойное нажатие и вторая вкладка не портят историю.
- **Оценка без ручного выбора.** Верный ответ — Good, быстрый верный выбор в узнавании, аудировании и
  понимании на слух — Easy, «Почти» — Hard, неверный ответ и «Не знаю» — Again. Время ответа читается
  только у заданий с готовыми вариантами: в сборке, написании и пропуске оно говорит о длине слова,
  а не о лёгкости вспоминания. «Почти» остаётся ошибкой навыка и даёт дополнительную тренировку,
  но интервал не сбрасывает.
- **Ступень перед письмом.** Слово сначала собирается из перемешанных слогов (артикль — отдельная плитка),
  написание от руки открывается после одной чистой сборки; ошибка в написании снова требует сборки.
  Деление на слоги считается по правилам новогреческого, см. `openspec/changes/archive/2026-09-16-add-syllable-assembly-exercise/`.
- **Ступень вниз после ошибки.** Под написанием — сборка, под сборкой и пониманием на слух — узнавание,
  под пропуском — тот же пропуск с четырьмя вариантами ответа. Попытка идёт в режиме practice
  и долгосрочное расписание не двигает.
- **Ручная тренировка** слова, набора или отдельной группы карточек урока в режиме practice — навык фиксируется,
  интервалы FSRS не сдвигаются.
- **Слова и уроки.** Страницы по 50 карточек с устойчивым курсором, поиск по началу слов среди загруженных
  на устройство (индекс токенов без учёта диакритики), фильтры по набору и состоянию, редактор слова,
  примеры, загрузка своей картинки и аудио, мягкое удаление, создание наборов без даты и перенос даты.
- **Выборочный доступ к данным.** Экраны, планировщик, сессия и статистика читают только нужные записи по
  индексам IndexedDB: план дня не читает таблицы слов, событий и сессий, карточки загружаются только для
  выбранной сессии и ограниченного пула вариантов ответа, история — только для слов сессии.
- **Подготовка урока агентом.** Присланный материал превращается в исходники по инструкции
  [`docs/lesson-authoring.md`](docs/lesson-authoring.md): режимы поручения `extract`/`transform`/`generate`,
  правило «только присланное и запрошенное», происхождение каждой фразы и пропуска, конвенция имён учебной цели
  и правила повторной обработки. Шаблоны форматов — в [`docs/lesson-authoring/`](docs/lesson-authoring/),
  вызов инструкции в новой сессии агента — навык [`.agents/skills/prepare-lesson`](.agents/skills/prepare-lesson/SKILL.md).
- **Импорт Quizlet** (чередование строк и TSV) с предпросмотром, дубликатами и транзакционным сохранением.
- **Статистика** за 7 дней, сроки, состояние карточек и доля успешных ответов по типам проверки (включая
  понимание на слух и заполнение пропуска) с числом попыток. Отдельный раздел «Не даётся» показывает карточки
  с восемью и более провалами: из программы они не убираются, решение остаётся за пользователем. Результат
  занятия показывает уникальные карточки и их состав по видам; повторная попытка не удваивает счёт. Устойчивой
  считается карточка с интервалом от 21 дня — это состояние карточки, а не заявление об освоении грамматической темы.
- **Офлайн и копии.** PWA precache оболочки, хранение в IndexedDB (схема 6: карточки трёх видов, типизированные
  связи `lessonItems`, состояния `cardStates` по ключу вида и идентификатора, метаданные пакетов, описания медиа),
  полный экспорт/восстановление с миграцией копий схем 1–5 и проверкой целостности до замены данных,
  отдельный TSV-экспорт слов. Переход на схему 6 проходит без сети: словарные ключи, события, базы навыков,
  отложенный прогресс и незавершённые занятия копируются с сохранением идентификаторов, сроков и версий.
  Копия с фразами и пропусками без слов допустима. Автоматического отката базы к прежней схеме нет.

## Telegram Mini App

Тот же клиент открывается внутри Telegram как Main Mini App бота `@TaveloriBot` (ссылка `https://t.me/TaveloriBot?startapp`;
для разработки — `@TaveloriDevBot`). Обычный веб-адрес и PWA продолжают работать без Telegram и регистрации.

- **Единая сборка, изолированный адаптер.** `src/platform/` загружает официальный bridge, не блокируя рендер, проверяет
  каждую возможность отдельно (BackButton с 6.1, HapticFeedback, MainButton, CloudStorage с 6.9) и переводит тему и размеры
  в переменные оболочки. Нативный «Назад» и внутренняя стрелка вызывают один обработчик; на «Сегодня» кнопка скрыта.
  Тактильный отклик — один раз после сохранённого ответа, с выключателем в настройках.
- **Раздельные профили.** Браузер хранит данные в базе `lexi`, Telegram — в `lexi-tg-<бот>-<пользователь>`. Перенос между
  режимами только полной копией; старую браузерную базу можно перенести в Telegram-профиль явным действием при первом запуске.
- **Компактный прогресс через CloudStorage.** Состояния FSRS и навыков поставляемых карточек всех трёх видов, темп курса,
  даты уроков и сводная статистика синхронизируются между устройствами одного аккаунта (`src/sync/`, формат снимка 2):
  вид карточки входит в идентичность прогресса, причинные версии по устройствам, части ≤ 4000 символов с контрольной суммой,
  указатель публикуется последним, конфликты решаются выбором целой версии с сохранением альтернатив, лимиты
  1024 ключа / 4096 символов проверяются до записи. Новый клиент читает словарный формат 1 как прогресс слов, но не применяет
  его поверх уже накопленного прогресса фраз и пропусков; старый клиент отвергает формат 2 и не перезаписывает его.
  Прогресс карточек, пакет которых ещё не установлен, ждёт установки отдельно. История ответов, сессии, тексты карточек,
  введённые ответы, описания учебной цели, свои слова и медиа остаются локальными.
- **Честные деградации.** Отказ воспроизведения даёт повтор или пропуск без штрафа; сохранение копии идёт через файловый share
  или скачивание с нейтральным статусом; без service worker приложение работает онлайн.
- **Отчёты о сбоях без сервера.** Непойманные исключения, отказы промисов и падения дерева интерфейса уходят в Sentry
  (`src/reporting/`): SDK подгружается отдельным чанком после первого рендера, ранние ошибки копятся до его загрузки,
  без сети отчёт ждёт в отдельной базе IndexedDB. В отчёте — стек, версия приложения и сборки, среда (веб или Telegram)
  с версией клиента, путь экрана без параметров и крошки сворачивания Mini App с размерами окна. Слова, переводы, ответы,
  прогресс, идентификатор пользователя, `initData` и консоль не отправляются; очистка события — чистые функции с тестами.
  Отдельно сообщаются отказ открытия базы, отклонённый пакет урока, ошибка синхронизации и отказ service worker.
  Переключатель «Отправлять отчёты об ошибках» в «Настройках» включён по умолчанию; канал описан на экране «Копия данных».
  Падение дерева даёт экран сбоя с перезапуском и копированием диагностики, занятие в базе не теряется.
  Адрес приёма задаётся при сборке переменной `VITE_SENTRY_DSN`: без него (разработка, тесты, проверки pull request)
  код отчётов не загружается и запросов к сервису нет. Публикация загружает скрытые карты кода в Sentry
  (`SENTRY_AUTH_TOKEN`, `SENTRY_ORG`, `SENTRY_PROJECT`) и не выкладывает их на сайт; `npm run check:bundle` следит,
  что стартовый чанк не растёт и SDK лежит отдельно.

Документация: `docs/telegram.md` (настройка BotFather, границы, откат, матрица устройств), `docs/telegram-dev.md`
(локальная разработка через туннель, `TUNNEL_HOST`), `docs/telegram-snapshot.md` (поля и размеры снимка),
`docs/origin-migration.md` (возможная смена адреса). Проверки на реальных iOS и Android ещё не выполнены и отмечены в матрице.

## Известные ограничения

- **Аудио.** Локальных аудиофайлов для 63 исходных слов нет: озвучка идёт системным греческим голосом (`el-GR`),
  а при его отсутствии аудирование честно отключается. Свой файл можно загрузить в редакторе слова —
  он сохраняется в базу и попадает в полную копию. Когда файлы появятся в `content/audio`, они попадут в пакеты
  как обязательные медиа и будут учитываться в готовности урока офлайн.
- **Поиск.** Ищет по началу слов только среди уроков, загруженных на устройство; словарь неустановленных уроков каталога
  поиском не охвачен.
- **Фонетика.** IPA и разборы чтения подготовлены по правилам чтения стандартного новогреческого и проверены
  вручную, но не сверены со словарными изданиями построчно. Пользовательские правки IPA помечаются непроверенными.
- **Иллюстрации.** Это собственные векторные рисунки, а не фотографии; для абстрактных слов нарисованы ситуации.
- **Примеры употребления.** Составлены для Lexi на стандартном новогреческом. Предложение можно прослушать системным греческим голосом; записанных аудиофайлов для примеров нет, без голоса кнопка отключена.
- Кипрская диалектная норма не поддерживается — используется стандартный новогреческий.
- Распознавание речи и аккаунты в эту версию не входят.
- **Фразы и пропуски: формат поддержан, материала пока нет.** Приложение умеет устанавливать и учить смешанные уроки,
  но в каталоге сейчас только словарные уроки: первый настоящий смешанный урок появится, когда пользователь пришлёт
  материал и его подготовят по [инструкции](docs/lesson-authoring.md). Проверочные примеры живут в тестовой фикстуре
  и в каталог не публикуются.

## Интерфейс

Компоненты — [shadcn/ui](https://ui.shadcn.com) (базовый реестр, примитивы Base UI) поверх Tailwind CSS v4.
Исходники компонентов лежат в `src/components/ui` и правятся под наш макет: у Button добавлены размеры
`xl`/`md` и варианты `soft`/`quiet`, у Card — отступы и скругление Lexi, у Badge — вариант `soft`,
у Alert — `warning`. Палитра Lexi задана токенами shadcn в `src/styles.css`, поэтому компоненты реестра
сразу выглядят как остальное приложение.

CSS-модули остались там, где компонента-аналога нет: раскладка экрана (`shared/ui.module.css`),
карточка слова (`shared/word.module.css`), нижняя навигация и шапка, а также экран занятия
с закреплённым доком (`features/learning/session.module.css`).

ReUI рассматривался как реестр компонентов: подключается тем же CLI, но Button, Card, Input, Select,
Progress и остальные его компоненты отдаются только по платному ключу `REUI_LICENSE_KEY` — бесплатны
лишь Badge и Alert. Поэтому используется базовый реестр shadcn.

```
content           исходники контента: words/*.yaml, phrases/*.yaml, clozes/*.yaml, lessons/*.yaml, art/*.svg и генератор build.ts
docs/lesson-authoring инструкция и шаблоны подготовки урока агентом; навык — .agents/skills/prepare-lesson

src/content       контракт каталога и пакетов с валидаторами, клиент установки, медиа по запросу
src/components/ui компоненты shadcn/ui, подогнанные под макет
src/features      экраны: сегодня, уроки, слова, занятие, статистика, импорт, копия
src/shared        часы, формат, аудио, медиа-валидация, офлайн-статус
src/reporting     отчёты о сбоях: лёгкая точка входа с буфером ранних ошибок, очистка события, привязка к настройке, чанк SDK
scripts           проверка сборки: предел стартового чанка, SDK отдельным чанком, отсутствие карт кода в dist
```
