# Lexi — греческий к каждому занятию

Личный тренажёр греческих слов: наборы по расписанию занятий, карточки с картинкой, IPA и разбором чтения,
четыре типа упражнений и интервальные повторения FSRS. Всё работает локально, без регистрации и сервера.

Приложение: **https://tavelori.app/** — публикуется автоматически из `main` через GitHub Pages (custom domain репозитория `lavich/Tavelori`).

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # production build
npm run preview    # запуск собранного приложения
npm test           # unit и integration тесты (Vitest)
npm run test:e2e   # браузерные проверки по production build (Playwright, Chromium)
```

## Что уже есть

- **Каталог и уроки по запросу.** При запуске приложение получает только оболочку и небольшой каталог
  (`content/catalog.json`); словарь в стартовый JavaScript и precache не входит. Урок 1.1 (33 слова),
  урок 1.2 (30 слов, дата 18 сентября 2026) и уроки 1.3 и 1.4 показаны в каталоге и загружаются при
  открытии урока одним пакетом; картинки и аудио подгружаются при просмотре, а «Скачать для офлайн»
  забирает все обязательные медиа урока и проверяет их наличие. Установка транзакционная, повторные
  запросы объединяются, повреждённый или несовместимый пакет отклоняется без частичного урока.
- **Обновление контента без потери правок.** У поставленных слов хранится ревизия и признак локальной
  правки; новая версия пакета заменяет нетронутые записи, а отредактированные, удалённые слова и убранные
  из урока связи сохраняются, о конфликтах сообщается. Идентификаторы и прогресс не меняются.
- **Исходники контента в YAML.** Одно слово — один файл с греческим именем (`content/words/το-σπίτι.yaml`),
  урок — список идентификаторов в `content/lessons/`, иллюстрации — `content/art/το-σπίτι.svg`. Поле `id` внутри
  файла хранит стабильный идентификатор; у нового слова его можно не указывать. `npm run content` (вызывается
  сам перед `dev` и `build`) проверяет исходники и собирает каталог, версионированные пакеты и медиа в
  `public/content`.
- **Расписание занятий.** На экране «Уроки» задаются день первого занятия и дни недели; предстоящие наборы
  без своей даты получают дни расписания по порядку номеров в названии («1.9» < «1.10» < «2.1»). Дата,
  заданная на экране урока, становится якорем и сдвигает следующие наборы; её можно вернуть в расписание.
  Урок, чей день прошёл, при запуске и при смене дня закрепляется проведённым со своей датой, поэтому
  изменение расписания не трогает прошедшие занятия.
- **Карточка слова.** Собственная иллюстрация, IPA, объяснение ударения, интерактивный разбор буквосочетаний
  и пример употребления с переводом; слово и предложение озвучиваются.
- **План дня.** Накопительный темп по всем ближайшим датам, дневной лимит новых слов, очередь
  relearning → просроченные → сегодняшние.
- **Занятие.** Знакомство, «вспомни слово» с самооценкой, выбор перевода, аудирование, сборка слова
  из слогов и написание с посимвольной обратной связью. Ответ сохраняется атомарно: двойное нажатие
  и вторая вкладка не портят историю.
- **Ступень перед письмом.** Слово сначала собирается из перемешанных слогов (артикль — отдельная плитка),
  написание от руки открывается после двух чистых сборок; ошибка в написании снова требует двух сборок.
  Деление на слоги считается по правилам новогреческого, см. `openspec/changes/add-syllable-assembly-exercise/`.
- **Ручная тренировка** слова или набора в режиме practice — навык фиксируется, интервалы FSRS не сдвигаются.
- **Слова и уроки.** Страницы по 50 карточек с устойчивым курсором, поиск по началу слов среди загруженных
  на устройство (индекс токенов без учёта диакритики), фильтры по набору и состоянию, редактор слова,
  примеры, загрузка своей картинки и аудио, мягкое удаление, создание наборов без даты и перенос даты.
- **Выборочный доступ к данным.** Экраны, планировщик, сессия и статистика читают только нужные записи по
  индексам IndexedDB: план дня не читает таблицы слов, событий и сессий, карточки загружаются только для
  выбранной сессии и ограниченного пула вариантов ответа, история — только для слов сессии.
- **Импорт Quizlet** (чередование строк и TSV) с предпросмотром, дубликатами и транзакционным сохранением.
- **Статистика** за 7 дней, сроки, состояние словаря и доля успешных ответов по навыкам с числом попыток.
- **Офлайн и копии.** PWA precache оболочки, хранение в IndexedDB (схема 2: связи `lessonWords`, метаданные
  пакетов, описания медиа), полный экспорт/восстановление с миграцией копий старого формата и проверкой
  целостности до замены данных, отдельный TSV-экспорт слов.

## Telegram Mini App

Тот же клиент открывается внутри Telegram как Main Mini App бота `@TaveloriBot` (ссылка `https://t.me/TaveloriBot?startapp`;
для разработки — `@TaveloriDevBot`). Обычный веб-адрес и PWA продолжают работать без Telegram и регистрации.

- **Единая сборка, изолированный адаптер.** `src/platform/` загружает официальный bridge, не блокируя рендер, проверяет
  каждую возможность отдельно (BackButton с 6.1, HapticFeedback, MainButton, CloudStorage с 6.9) и переводит тему и размеры
  в переменные оболочки. Нативный «Назад» и внутренняя стрелка вызывают один обработчик; на «Сегодня» кнопка скрыта.
  Тактильный отклик — один раз после сохранённого ответа, с выключателем в настройках.
- **Раздельные профили.** Браузер хранит данные в базе `lexi`, Telegram — в `lexi-tg-<бот>-<пользователь>`. Перенос между
  режимами только полной копией; старую браузерную базу можно перенести в Telegram-профиль явным действием при первом запуске.
- **Компактный прогресс через CloudStorage.** Состояния FSRS и навыков стандартных слов, настройки, даты уроков и сводная
  статистика синхронизируются между устройствами одного аккаунта (`src/sync/`): причинные версии по устройствам, части
  ≤ 4000 символов с контрольной суммой, указатель публикуется последним, конфликты решаются выбором целой версии с сохранением
  альтернатив, лимиты 1024 ключа / 4096 символов проверяются до записи. История ответов, сессии, свои слова и медиа остаются
  локальными.
- **Честные деградации.** Отказ воспроизведения даёт повтор или пропуск без штрафа; сохранение копии идёт через файловый share
  или скачивание с нейтральным статусом; без service worker приложение работает онлайн.

Документация: `docs/telegram.md` (настройка BotFather, границы, откат, матрица устройств), `docs/telegram-dev.md`
(локальная разработка через туннель, `TUNNEL_HOST`), `docs/telegram-snapshot.md` (поля и размеры снимка),
`docs/origin-migration.md` (возможная смена адреса). Проверки на реальных iOS и Android ещё не выполнены и отмечены в матрице.

## Известные ограничения

- **Аудио.** Локальных аудиофайлов для 63 исходных слов нет: озвучка идёт системным греческим голосом (`el-GR`),
  а при его отсутствии аудирование честно отключается. Свой файл можно загрузить в редакторе слова —
  он сохраняется в базу и попадает в полную копию. Когда файлы появятся в `content/audio`, они попадут в пакеты
  как обязательные медиа и будут учитываться в готовности урока офлайн.
- **Поиск.** Ищет по началу слов только среди уроков, загруженных на устройство; словарь неустановленных уроков каталога
  поиском не охвачен.
- **Фонетика.** IPA и разборы чтения подготовлены по правилам чтения стандартного новогреческого и проверены
  вручную, но не сверены со словарными изданиями построчно. Пользовательские правки IPA помечаются непроверенными.
- **Иллюстрации.** Это собственные векторные рисунки, а не фотографии; для абстрактных слов нарисованы ситуации.
- **Примеры употребления.** Составлены для Lexi на стандартном новогреческом. Предложение можно прослушать системным греческим голосом; записанных аудиофайлов для примеров нет, без голоса кнопка отключена.
- Кипрская диалектная норма не поддерживается — используется стандартный новогреческий.
- Синхронизация между устройствами, аккаунты и распознавание речи в эту версию не входят.

## Интерфейс

Компоненты — [shadcn/ui](https://ui.shadcn.com) (базовый реестр, примитивы Base UI) поверх Tailwind CSS v4.
Исходники компонентов лежат в `src/components/ui` и правятся под наш макет: у Button добавлены размеры
`xl`/`md` и варианты `soft`/`quiet`, у Card — отступы и скругление Lexi, у Badge — вариант `soft`,
у Alert — `warning`. Палитра Lexi задана токенами shadcn в `src/styles.css`, поэтому компоненты реестра
сразу выглядят как остальное приложение.

CSS-модули остались там, где компонента-аналога нет: раскладка экрана (`shared/ui.module.css`),
карточка слова (`shared/word.module.css`), нижняя навигация и шапка, а также экран занятия
с закреплённым доком (`features/learning/session.module.css`).

ReUI рассматривался как реестр компонентов: подключается тем же CLI, но Button, Card, Input, Select,
Progress и остальные его компоненты отдаются только по платному ключу `REUI_LICENSE_KEY` — бесплатны
лишь Badge и Alert. Поэтому используется базовый реестр shadcn.

## Структура

```
content           исходники контента: words/*.yaml, lessons/*.yaml, art/*.svg и генератор build.ts
src/domain        чистая логика: типы, импорт, календарь, план и сессия над источником данных, FSRS-адаптер, статистика
src/storage       Dexie: схема и миграция, выборочные запросы по индексам, транзакционные операции
src/content       контракт каталога и пакетов с валидаторами, клиент установки, медиа по запросу
src/components/ui компоненты shadcn/ui, подогнанные под макет
src/features      экраны: сегодня, уроки, слова, занятие, статистика, импорт, копия
src/shared        часы, формат, аудио, медиа-валидация, офлайн-статус
```
